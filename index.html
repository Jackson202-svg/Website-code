BEGINNER GUIDE • VS CODE

Build your first website in VS Code.

Learn the simple HTML + CSS + JavaScript workflow, one step at a time.

Start learning →

THE WORKFLOW

From empty folder to live webpage

01

Install VS Code

Download Visual Studio Code and open it on your computer.

Get VS Code ↗
02

Create a project folder

Make a folder such as my-first-website, then open that folder in VS Code.

03

Create your files

Add index.html, style.css, and script.js.

04

Write the HTML

HTML creates the structure: headings, paragraphs, buttons, images, and sections.

05

Style with CSS

CSS controls colors, spacing, fonts, layouts, responsive design, and animations.

06

Add JavaScript

JavaScript makes the page interactive, such as buttons, menus, forms, and dynamic content.

STARTER CODE

Your first three files

index.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Website</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Hello, world!</h1>
  <p>I built this website in VS Code.</p>
  <script src="script.js"></script>
</body>
</html>
style.css
body {
  font-family: Arial, sans-serif;
  max-width: 900px;
  margin: 0 auto;
  padding: 40px 20px;
}

h1 {
  font-size: 3rem;
}

p {
  font-size: 1.1rem;
}
script.js
const heading = document.querySelector("h1");

heading.addEventListener("click", () => {
  heading.textContent = "You clicked it!";
});
