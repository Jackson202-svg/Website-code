# Build Your First Website in VS Code

A beginner-friendly website that teaches the basic workflow for building a website with Visual Studio Code.

## Files

- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — copy buttons and interaction

## Run it in VS Code

1. Open this repository folder in VS Code.
2. Open `index.html`.
3. Install the **Live Server** extension if you want automatic browser refresh.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Edit the files and save to see your changes.

You can also open `index.html` directly in a browser.
